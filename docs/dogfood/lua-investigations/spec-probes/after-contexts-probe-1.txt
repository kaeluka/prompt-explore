Here's an executable Lua orchestration program that reads `config.json` via the scenario's `read_file` tool, then calls an agent, and retries up to two times if the agent does not produce a final output. It uses the documented `ctx.call_tool` and `ctx.run_agent` functions, with no workspace or additional limits specified beyond the default.

```lua
return function(p, ctx)
  -- Read config.json from the scenario's file system
  local file = ctx.call_tool('read_file', {path='config.json'})
  if file.error then
    error(file.error)
  end

  -- Retry the agent call up to 2 times if no final output
  for attempt=1,3 do
    local agent = ctx.run_agent{
      prompt=p.prompt,
      model=p.model,
      input=file.content
    }
    if agent.failure ~= nil then
      error(agent.failure.error)
    end
    if agent.output ~= nil then
      return agent.output
    end
  end

  -- If all retries fail, return a failure indicator
  return {delivered=false}
end
```
